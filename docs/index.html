✨ 核心功能 #features

💽 磁盘 & 文件管理
扫描所有盘符，进度条可视化使用率。10 种配色按文件类型分类，到阈值自动弹桌面通知。
🛰️ 后台服务监控
150+ 条规则三层分类引擎：有益 / 无益 / 未知。可一键桌面通知可疑进程、定位路径、终止。
🎨 暗夜贴纸 UI
手绘标题 + 涂鸦 SVG + 不干胶卡片，刻意避开 AI 模板常见的冷蓝色 + 完美对齐。
⚡ 双模式启动
Web UI 浏览器界面（7788 端口）+ CLI 命令行 Rich 表格，同一份代码两种玩法。
🔔 跨平台通知
plyer 桌面通知（Windows / macOS / Linux 都弹窗），失败自动降级 colorama 控制台彩色。
📦 单文件二进制
PyInstaller 打包，无需安装 Python，双击即用。GitHub Actions 自动构建三平台。

🚀 运行方式 #run

🐧 Linux / macOS
$ chmod +x PersonalDebugConsole-v1.0.0-linux $ ./PersonalDebugConsole-v1.0.0-linux # 交互式：选 1 = Web UI $ ./PersonalDebugConsole-v1.0.0-linux web # 直接启动 Web UI $ ./PersonalDebugConsole-v1.0.0-linux cli # 直接进入 CLI
🪟 Windows
# 双击 .exe 即可，或在 PowerShell： PS> .\PersonalDebugConsole-v1.0.0-windows.exe PS> .\PersonalDebugConsole-v1.0.0-windows.exe web -p 8888
